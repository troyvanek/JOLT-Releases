# Security Policy

## Supported versions

Security fixes are made against the latest stable JOLT release. If you are using an older version, check whether the issue also affects the latest release when practical.

## Reporting a vulnerability

Use [GitHub’s private vulnerability reporting form](https://github.com/troyvanek/JOLT-Releases/security/advisories/new) for security issues in JOLT, its installers, or its update process. Please keep the details private while the report is reviewed.

Include the affected JOLT version, operating system, affected component, potential impact, and enough detail to understand the issue. Redact passwords, tokens, private server addresses, and personal data from logs or screenshots.

Use public issues for ordinary bugs and feature requests.
